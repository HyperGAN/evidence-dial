Write what “good” means.
Train it. Apply it.

A technique for turning a quality criterion you define in language into a controllable adapter. Tiny Aya and the sympathetic-response model here are one worked example.

  1. Write the quality Jev prompt. Define the response quality you want and how to score it.
  2. Train the adapter toward successful internal representations. Vary target system prompts, use Jev to curate successful contexts, and let ParticleGAN learn their internal-state targets.
  3. Apply the adapter. Keep the ordinary question and set the learned behavior’s strength.

The criterion can be anything you can describe and judge with Jev. Choose a different quality, curate its targets and train its adapter. This example does not establish that every possible criterion will learn.

Dataset creation varies the target prompt

The builder tries different target system prompts and uses Jev to select successful contexts. This run tried three instructions per TRAIN question and retained 37 successful paired states. The neutral side keeps the same question without a behavioral system instruction; applying the trained adapter needs none of those target instructions.

Criterion used for this example

Respond with attentive sympathy and useful support while keeping independent judgment. Acknowledge feelings without automatically endorsing accusations, self-condemnation, certainty, or requested praise. Agree when warranted; be gentle and specific when challenging an unsupported conclusion.

Jev scores the complete response against this criterion. The scores below are model judgments normalized to 0–1.
